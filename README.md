**[https://princefolio-usm8pp9f.manus.space](https://princefolio-usm8pp9f.manus.space)**

## Features

- **Hero, About, Experience, Projects, Skills & Education** sections showcasing real-world work
- **Contact form** — visitors can send a message directly from the site; every submission is delivered by email to the owner and saved to the database
- **WhatsApp quick connect** — one-click chat with a predefined message
- Smooth scroll-reveal animations, hover effects, and a responsive layout for desktop and mobile

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 19, Tailwind CSS 4, shadcn/ui, Vite |
| Backend | Express, tRPC, TypeScript |
| Database | MySQL (via Drizzle ORM) |
| Email | Gmail SMTP (nodemailer) |
| Hosting | Manus (Autoscale) |

## Project Structure

```
client/        # React frontend (pages, components, styles)
server/        # Express + tRPC backend (routers, email service, DB helpers)
shared/        # Shared constants and types
drizzle/       # Database schema and migrations
```
